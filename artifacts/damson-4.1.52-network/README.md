# Damson Linux 4.1.52 network modules

These 44 IPKs and their matching `.ko` files were exported by [GitHub Actions run 37967909372](https://github.com/FrancYescO/GUI_ipk/actions/runs/37967909372) from the successful [Damson module build 37940783813](https://github.com/FrancYescO/GUI_ipk/actions/runs/37940783813).

They target the Damson firmware with Linux 4.1.52. Their hashes, IPK contents, ELF architecture, and module vermagic were checked. **These 44 modules have not been tested on the router.** Only the separate `tun` and `act_connmark` IPKs in `../damson-4.1.52-manual/` have been tested there.

The packages are manual installation artifacts. They contain no autoload configuration or installation scripts. Install a module only when its dependencies and the running kernel match.
